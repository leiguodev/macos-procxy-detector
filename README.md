# macOS 代理检测工具

检测 macOS 系统上的代理状态，包括系统代理、TUN 模式、各应用代理配置。

## 功能

- 检测系统代理设置（HTTP/HTTPS/SOCKS/PAC）
- 检测 TUN 模式（虚拟网卡）
- 检测 Clash 进程状态
- 检测各应用代理配置（Safari、Chrome、VS Code）
- 检测实际出口 IP
- 持续监控模式

## 使用方法

```bash
# 一次性检测
python proxy_detector.py

# 持续监控，每5秒刷新
python proxy_detector.py --watch

# 持续监控，每3秒刷新
python proxy_detector.py --watch -i 3

# JSON 格式输出
python proxy_detector.py --json
```

## 依赖

- Python 3.8+
- curl（macOS 自带）

## 代理优先级判断

1. **TUN 模式**（最高优先级）：在系统网络层接管所有流量，应用层无法绕过
2. **应用独立代理配置**：VS Code `http.proxy` 设置、Chrome `--proxy-server` 启动参数
3. **系统代理设置**：HTTP/HTTPS/SOCKS 代理、PAC 自动配置
4. **直连**：无代理
